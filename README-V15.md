# V15 — implémentation fidèle aux maquettes validées

Cette version repart des deux maquettes de référence desktop et mobile.

Principes appliqués :
- maquettes incluses dans `reference/` pour contrôle visuel ;
- portrait d’Antoine indépendant du background ;
- carte blanche au-dessus du portrait ;
- responsive desktop et mobile distincts ;
- aucun scroll horizontal ;
- palette violet / magenta / rose / corail harmonisée jusqu’au footer ;
- contenus textuels conformes au brief ;
- fonctionnalités existantes conservées : Facebook Login, import local, éditeur, zoom, overlay, export, partage et pages légales.

Le fichier `DESIGN-SPEC-V15.txt` contient le cahier des charges utilisé pour cette version.
