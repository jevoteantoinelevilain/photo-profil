# V20 mobile

Cette version reconstruit uniquement la couche mobile (`<= 700px`) en conservant le desktop existant.

Principaux changements :
- titre mobile en trois lignes visuelles sans chevaucher le visage ;
- portrait repositionné à droite ;
- paragraphe élargi sur toute la largeur utile et autorisé à passer devant le costume ;
- carte blanche replacée dans le flux normal, entièrement visible et avec ses quatre coins arrondis ;
- composants de la carte redimensionnés pour mobile ;
- étapes 2 et 3 harmonisées ;
- titres et descriptions des étapes 2 et 3 forcés en blanc ;
- footer compact ;
- suppression du scroll horizontal ;
- logique JS, Facebook, canvas et overlay conservés.
