Suppression des données utilisateur

Cette version du site ne conserve pas de base de données contenant les photos, profils Facebook ou listes nominatives des utilisateurs. La photo utilisée pour créer le visuel est traitée temporairement dans le navigateur.

Révoquer l’accès Facebook

Si vous avez utilisé « Utiliser ma photo Facebook », vous pouvez retirer l’autorisation accordée à l’application depuis les réglages Facebook, dans la rubrique consacrée aux applications et sites web, puis supprimer l’application de votre compte.
