# V29 — Ouvrir Facebook avec le visuel généré

- Le bouton `Ouvrir Facebook` déclenche maintenant le partage natif du fichier généré lorsque le navigateur/appareil le permet.
- Sur mobile compatible, la feuille de partage système reçoit directement l'image générée ; l'utilisateur peut choisir Facebook puis valider sa publication.
- Si le partage natif de fichiers n'est pas disponible, le bouton ouvre Facebook comme auparavant.
- Aucune modification de l'éditeur, de l'overlay ou des autres fonctionnalités.
