# V19 Mobile — refonte complète

Cette version conserve le rendu desktop V18 et charge une feuille `css/mobile.css` uniquement pour les écrans de 700 px et moins.

Principaux changements mobile :
- reconstruction du hero avec proportions compactes ;
- titre visuellement réparti « Créez votre / photo de / soutien » ;
- portrait repositionné à droite, sans chevaucher le visage ;
- carte blanche remontée et superposée au bas du portrait ;
- cercle d’étape, boutons et texte de confidentialité redimensionnés ;
- footer compact et cohérent avec la référence ;
- suppression du scroll horizontal ;
- logique métier, assets portrait et overlay inchangés.
